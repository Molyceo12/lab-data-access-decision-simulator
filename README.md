# Data Access Decision Simulator

**Prepared by:** Irimaso Maurice

## Overview
Data access decisions for EduConnect Ghana, an ed-tech platform with 50,000+ students.
Three access requests are assessed against the company's data classification policy
(PUBLIC / INTERNAL / CONFIDENTIAL), the principle of least privilege, the data
lifecycle, and Ghana's Data Protection Act, 2012 (Act 843).

## Decisions
| Request | Decision | Lifecycle stage |
|---|---|---|
| 1. Marketing campaign (Sarah Owusu) | Deny raw export; conditional platform-based alternative | Use / Share |
| 2. Analytics partnership (David Mensah) | Deny; treat shared credentials as a security incident | Share (cross-border) |
| 3. Deletion request (James Boateng) | Approve with limited lawful retention | Destroy / Archive |
